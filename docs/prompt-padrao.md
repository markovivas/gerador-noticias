# PROMPT PADRÃO — ARTE DE NOTÍCIA

Este documento define as regras oficiais para criação de artes de notícias no Affinity.

Todas as artes devem seguir este padrão visual e operacional.

---

# 1. OBJETIVO

Criar uma arte padronizada de notícia utilizando o arquivo-modelo oficial:

\artes\modelos\capa_noticia.af

O modelo deve ser preservado integralmente.

A arte final deve manter a identidade visual, estrutura, proporções, cores, tipografia e elementos gráficos existentes no modelo.

---

# 2. ARQUIVO-MODELO

Arquivo oficial:

\artes\modelos\capa_noticia.af

O arquivo-modelo é somente uma base.

NUNCA editar, sobrescrever, renomear ou modificar diretamente o arquivo original.

Antes de iniciar qualquer edição, deve ser criada uma cópia em:

\artes\projetos\

O arquivo de trabalho deve seguir o padrão:

noticia-ID-DD-MM-AAAA.af

Onde:

- ID = identificação da notícia
- DD = dia
- MM = mês
- AAAA = ano

Exemplo:

noticia-1523-07-09-2026.af

---

# 3. ESTRUTURA DO MODELO

O modelo possui elementos gráficos e camadas que fazem parte da identidade visual da arte.

A estrutura existente deve ser preservada.

Não modificar, remover, renomear, reorganizar ou deslocar camadas que não sejam explicitamente definidas como editáveis.

---

# 4. CAMADAS EDITÁVEIS

As únicas camadas que devem ser alteradas para cada notícia são:

- DONO NA IMAGEM
- TITULO
- SUB-TITULO
- FOTO

Todas as demais camadas devem permanecer como estão no modelo original.

---

# 5. DONO NA IMAGEM

Camada:

DONO NA IMAGEM

Esta camada deve conter o crédito da fotografia.

Utilizar somente o nome principal do crédito.

Exemplos:

Divulgação

Prefeitura Municipal

Assessoria de Comunicação

João Silva

Não adicionar automaticamente:

Foto:

Crédito:

Imagem:

Fotografia:

Caso o crédito não seja informado na notícia, utilizar:

Divulgação

O texto deve permanecer dentro da área e da formatação já definida pelo modelo.

---

# 6. TÍTULO

Camada:

TITULO

O título da arte deve possuir no máximo 3 palavras.

O título deve:

- representar o assunto principal da notícia;
- ser objetivo;
- ser jornalístico;
- ser facilmente compreendido;
- manter o sentido original da notícia.

Quando o título original possuir mais de 3 palavras, criar uma versão reduzida.

Não inventar informações.

Não modificar desnecessariamente a fonte, tamanho, posição ou estilo da camada.

Exemplo:

Título original:

Prefeitura anuncia novas medidas para saúde

Título da arte:

Novas medidas na saúde

---

# 7. SUB-TÍTULO

Camada:

SUB-TITULO

O subtítulo deve possuir no máximo 18 palavras.

O subtítulo deve resumir a informação mais importante da notícia.

Priorizar:

- clareza;
- objetividade;
- informação;
- linguagem jornalística.

Não inventar informações.

Não repetir desnecessariamente o título.

Não utilizar textos excessivamente longos.

Não modificar desnecessariamente a fonte, tamanho, posição ou estilo da camada.

---

# 8. FOTOGRAFIA

Camada:

FOTO

As fotografias das notícias ficam em:

\artes\imagens\

A imagem utilizada deve ser a que possui maior relação com a notícia.

Normalmente, o nome do arquivo da imagem terá relação com o assunto, título ou conteúdo da notícia.

A imagem deve ser incorporada ao documento do Affinity.

Não deixar a imagem apenas como arquivo vinculado.

---

# 9. AJUSTE DA FOTOGRAFIA

Ao substituir a fotografia:

- preservar o enquadramento do modelo;
- preservar a máscara existente;
- preservar o gradiente existente;
- preservar o posicionamento da área da fotografia;
- manter a proporção original da imagem;
- não deformar a fotografia;
- ajustar a escala proporcionalmente;
- preencher adequadamente a área destinada à fotografia.

Não alterar elementos gráficos que pertencem ao modelo.

---

# 10. IDENTIDADE VISUAL

A identidade visual do modelo deve ser preservada integralmente.

Manter:

- logos;
- ícones;
- redes sociais;
- gradientes;
- cores;
- formas;
- margens;
- espaçamentos;
- posicionamentos;
- tipografia;
- dimensões;
- elementos decorativos;
- estrutura geral da composição.

Não criar novos elementos gráficos sem necessidade.

Não alterar as cores do modelo.

Não substituir a tipografia do modelo.

Não redesenhar a arte.

---

# 11. COMPOSIÇÃO

A composição deve seguir exatamente a estrutura do arquivo-modelo.

O objetivo é que diferentes notícias pareçam fazer parte da mesma identidade visual.

Somente o conteúdo da notícia e a fotografia devem mudar.

Não alterar o layout para acomodar textos maiores.

Quando necessário, reduzir ou adaptar o texto respeitando os limites definidos neste documento.

---

# 12. REGRAS DE TEXTO

Todos os textos devem ser derivados exclusivamente das informações disponíveis na notícia.

Não inventar:

- nomes;
- números;
- datas;
- locais;
- acontecimentos;
- declarações;
- informações complementares.

Quando houver dúvida sobre uma informação, utilizar somente aquilo que estiver claramente informado na notícia.

Priorizar fidelidade ao conteúdo original.

---

# 13. REGRAS DE DATA

A data utilizada no nome do arquivo deve seguir:

DD-MM-AAAA

Exemplo:

07-09-2026

A data deve ser obtida da informação fornecida para a notícia.

Não utilizar a data atual automaticamente quando houver uma data específica da notícia.

---

# 14. NOME DO PROJETO

O arquivo editável deve utilizar:

noticia-ID-DD-MM-AAAA.af

Exemplo:

noticia-1523-07-09-2026.af

Salvar em:

\artes\projetos\

Resultado:

\artes\projetos\noticia-1523-07-09-2026.af

---

# 15. EXPORTAÇÃO

Após concluir a edição, exportar a arte final em PNG.

Pasta de destino:

\artes\exports\

Nome do arquivo:

noticia-ID-DD-MM-AAAA.png

Exemplo:

noticia-1523-07-09-2026.png

Resultado:

\artes\exports\noticia-1523-07-09-2026.png

Manter:

- dimensões originais do documento;
- proporção original;
- qualidade máxima disponível;
- composição integral da arte.

---

# 16. VALIDAÇÃO

Antes de finalizar a arte, verificar obrigatoriamente:

[ ] O arquivo-modelo original não foi alterado.

[ ] Foi criada uma cópia em \artes\projetos\.

[ ] O nome do projeto segue o padrão noticia-ID-DD-MM-AAAA.af.

[ ] O título possui no máximo 3 palavras.

[ ] O subtítulo possui no máximo 18 palavras.

[ ] O crédito da imagem foi preenchido.

[ ] O crédito utiliza "Divulgação" quando não informado.

[ ] A fotografia corresponde à notícia.

[ ] A fotografia está incorporada ao documento.

[ ] A fotografia não está deformada.

[ ] O texto não está cortado.

[ ] Nenhum elemento importante está sobreposto incorretamente.

[ ] Nenhuma camada estrutural do modelo foi modificada.

[ ] Logos e elementos gráficos foram preservados.

[ ] Cores e tipografia foram preservadas.

[ ] O layout original foi preservado.

[ ] O arquivo PNG foi exportado corretamente.

[ ] O arquivo editável foi salvo corretamente.

---

# 17. ARQUIVOS FINAIS

Cada notícia deve gerar dois arquivos.

PROJETO EDITÁVEL:

\artes\projetos\noticia-ID-DD-MM-AAAA.af

ARTE FINAL:

\artes\exports\noticia-ID-DD-MM-AAAA.png

---

# 18. REGRAS ABSOLUTAS

NUNCA:

- alterar o arquivo-modelo original;
- sobrescrever capa_noticia.af;
- alterar o prompt-padrao.md;
- alterar noticia.txt;
- modificar as imagens originais;
- inventar informações;
- utilizar fotografia não relacionada à notícia;
- deformar a fotografia;
- alterar o layout original;
- remover logos;
- remover elementos gráficos;
- alterar cores sem autorização;
- alterar a identidade visual;
- modificar camadas estruturais;
- exportar uma arte que esteja com texto cortado ou composição quebrada.

---

# 19. PRINCÍPIO PRINCIPAL

A arte deve parecer uma nova edição do mesmo modelo, e não uma nova criação.

A cada nova notícia:

CONTEÚDO NOVO + FOTOGRAFIA NOVA

mantendo:

LAYOUT + IDENTIDADE VISUAL + ESTRUTURA + TIPOGRAFIA + ELEMENTOS GRÁFICOS

O resultado deve ser consistente com todas as demais artes produzidas a partir deste modelo.
